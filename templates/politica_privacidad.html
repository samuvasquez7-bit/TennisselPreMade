PRIVACIDAD Y SEGURIDAD

Política de Privacidad

Normativa de recolección, uso, cifrado y protección de datos personales dentro de TENNISSEL.

Secciones
1. Recopilación de Datos 2. Finalidad del Tratamiento 3. Geolocalización (Mapa) 4. Seguridad Técnica 5. Proveedores Externos 6. Derechos ARCO

1. Información y Datos Personales Recopilados

Para habilitar los servicios del ecosistema TENNISSEL, nuestro sistema recopila categorías específicas de datos según el tipo de interacción[cite: 1]:

Datos de Identificación

Nombre completo, correo electrónico, credenciales encriptadas y rol (Jugador, Profesor, Comercio)[cite: 1].

Geolocalización

Coordenadas GPS y radio geográfico de búsqueda para el mapa en tiempo real[cite: 1].

Datos Deportivos

Nivel de juego, historial de reservas y parámetros del motor de emparejamiento (Matchmaking)[cite: 1].

Datos Transaccionales

Logs de reservas, cálculo de comisiones y token de pasarela de pago[cite: 1].

2. Finalidad del Tratamiento de los Datos

La información recolectada es procesada por nuestra arquitectura Backend en Python (Flask / Django)[cite: 1] con las siguientes finalidades operativas exentas de venta a terceros:

  • Conexión Estratégica: Facilitar el agendamiento y reserva inmediata entre deportistas, profesores independientes y locaciones[cite: 1].
  • Gestión Financiera: Cálculo y retención automatizada de la tasa de comisión administrativa (10%-15%)[cite: 1] y facturación de suscripciones B2C / B2B[cite: 1].
  • Notificaciones Segmentadas: Envío de alertas de noticias de última hora, cancelaciones repentinas y ofertas del Club de Descuentos para usuarios Premium[cite: 1].
  • Mejora Algorítmica: Evaluación de recomendaciones y eficiencia del Mapa Interactivo y del Módulo de Entrenamiento[cite: 1].

3. Tratamiento de Datos de Geolocalización (Mapa Interactivo)

El mapa dinámico utiliza tecnologías como Google Maps API o Mapbox para posicionar canchas, tiendas y bares deportivos[cite: 1].

Consentimiento Expreso: El acceso a las coordenadas en tiempo real del usuario únicamente se activa previa autorización del navegador o dispositivo móvil. Esta información se procesa en memoria volátil para renderizar los nodos cercanos y no se utiliza para seguimiento persistente fuera de la aplicación.

4. Protocolos de Seguridad Técnica y Almacenamiento

Conforme a los Requisitos No Funcionales del Sistema (RNF 3)[cite: 1], TENNISSEL implementa barreras de seguridad de nivel bancario:

  • Encriptación Transaccional: Transmisión de datos protegida mediante certificados HTTPS y cifrado TLS 1.3 activo.
  • Almacenamiento Seguro: Bases de datos relacionales normalizadas (PostgreSQL / MySQL)[cite: 1] con contraseñas encriptadas mediante algoritmos Hash Bcrypt.
  • Pasarelas Tokenizadas: Ningún dato completo de tarjetas de crédito o débito se almacena en nuestros servidores; los cobros son procesados mediante tokens seguros por proveedores certificados PCI-DSS[cite: 1].

5. Integraciones y Transferencia a Terceros

TENNISSEL interactúa con servicios externos autorizados mediante llamadas a APIs strictly configuradas[cite: 1]:

  • Proveedores de Analítica Deportiva (ej. Sportradar): Para la sincronización continua de marcadores, rankings ATP/WTA y noticias del circuito profesional[cite: 1].
  • Motores de Mapas Geográficos: Para la representación visual de coordenadas de locales e instructores[cite: 1].

En ningún caso comercializamos ni cedemos bases de datos personales a agencias publicitarias de terceros.

6. Derechos del Titular de Datos (Derechos ARCO)

Los usuarios de la plataforma conservan el derecho irrestricto a:

  1. Acceso y Rectificación: Consultar y modificar sus datos personales en cualquier momento desde el panel de perfil.
  2. Cancelación y Supresión: Solicitar la eliminación total y definitiva de su cuenta de usuario y registros asociados de nuestras bases de datos relacionales[cite: 1].
  3. Oposición al Envío de Alertas: Desactivar las notificaciones push o boletines informativos manteniendo activa su cuenta funcional.

Para ejercer sus derechos ARCO o hacer consultas sobre nuestra política de protección de datos, escríbanos a tennisselnuestrosaber@gmail.com.
